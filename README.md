# ArquitecturaComputadoras-MIPS-32-BITS
Procesador MIPS de 32 bits (5 etapas de Pipeline) diseñado en Verilog. Implementa Forwarding Unit, mitigación de riesgos (hazards) y ejecución nativa de código Ensamblador. Incluye simulación de los algoritmos Bubble Sort y Búsqueda Binaria a nivel de hardware.
